# CK-AspNet-Auth

[![Licence](https://img.shields.io/github/license/signature-opensource/CK-AspNet-Auth.svg)](LICENSE)

**Deprecated.** WebFrontAuth is replaced by the authentication made of Cris commands and an Authentication Center
(CK-Cris-TypeScript, CK-AppIdentity-Transport): see the [migration guide](https://github.com/signature-opensource/CK-Stack/blob/main/Docs/Migrations/v2026.282-to-explo-cris-auth.md).
The packages of this repository are tombstones: a project that depends on one of them fails to build with the
`CKDEPRECATED` error.

| Package | Description |
|---------|-------------|
| [CK.AspNet.Auth](CK.AspNet.Auth/README.md) | **Deprecated**: replaced by CK.Cris.AspNet.Authentication and the AuthCenter packages. |
| [CK.Testing.AspNetServer.Auth](CK.Testing.AspNetServer.Auth/README.md) | **Deprecated**: replaced by CK.Testing.AppIdentity.AuthCenter. |
